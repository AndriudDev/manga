# Skill: Manga UI Styling & Design Tokens

## Color Palette (Theme)
- **Background Dark:** `#121214`
- **Surface / Card Background:** `#1A1A1E`
- **Primary Accent (Manga Red):** `#FF334B`
- **Secondary Accent (Japan Neon):** `#70A1FF`
- **Text Main:** `#FFFFFF`
- **Text Muted:** `#8E8E93`
- **Error Border / Text:** `#FF453A`

## Component Standards
- **Buttons:**
  - Active state: Background `#FF334B`, Text `#FFFFFF`, Border Radius 12px.
  - Disabled state: Opacity 0.5.
  - Ripple/Touch effect enabled (`activeOpacity={0.8}`).
- **Input Fields:**
  - Background `#1A1A1E`, Border 1px solid `#2C2C2E`.
  - Focused / Error state: Border 1.5px solid `#FF334B`.
  - Placeholder color: `#8E8E93`.
